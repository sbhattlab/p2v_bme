# data

What the paper's scripts ([paper/README.md](../paper/README.md)) download and write, run from the repository root.
Everything here is git-ignored except this file; the scripts make the folders as they go.

```text
data/
├── datasets/<name>/        inputs: downloads (download_data) and simulated sets (simulate_data)
├── results/<experiment>/   raw results of the run_* scripts, read by make_tables
└── tables/                 the tables and the figures' data (make_tables), read by plots/
```

  generators and seeds of each set.

## results/

| Folder                                                                                  | Written by                                           | Read by `make_tables` (tables)                                                                                                  |
| --------------------------------------------------------------------------------------- | ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `scaling/`, `random_start/`, `seqlen/`, `representatives/`, `round_limit/`, `pandemic/` | `run_benchmarks --experiments <folder>`              | scaling, random_tree, baseline_10k, comparators, scaling_methods, seqlen, representative_sensitivity, maple; not `round_limit/` |
| `baselines/`                                                                            | `run_baselines` (`--run`, or recorded runs imported) | random_tree, maple, baseline_10k, comparators, scaling_methods                                                                  |
| `calibration/`                                                                          | `run_calibration`                                    | bootstrap                                                                                                                       |
| `fastme/`                                                                               | `run_fastme`                                         | fastme                                                                                                                          |
| `gtr_fit/`                                                                              | `run_gtr_fit_recovery`                               | gtr_fit                                                                                                                         |
| `silva/`                                                                                | `run_silva`                                          | silva_support, silva_clades, silva_gtdb                                                                                         |
| `viridian/`                                                                             | `run_viridian`                                       | viridian                                                                                                                        |

`run_benchmarks`' runs are in `<experiment>/<set>/<n>/`, named `rep<r>_seed<s>` (a dataset replicate and a seed), with
the tree (`.nwk`), the report (`.json`) and their scores; each script's `--help` lists its files.
